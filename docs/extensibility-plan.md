# 通用解耦实施计划

目标：新增业务、供应商和入口主要增加独立扩展文件与静态注册项；持久执行、身份、去重和恢复机制共用。保持默认免平台 Token、邮件关闭、旧任务和旧邮件记录兼容。

| 顺序 | 改造 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| 1 | 带 Schema、能力说明及生命周期的扩展注册；邮件供应商自描述 | 第三种测试供应商无需改配置解析器/工厂；注入优先、资源关闭可验证 | 已完成 |
| 2 | 通用渠道任务入口与投递策略；签名 Webhook 通道 | 邮件和 Webhook 共用身份/任务处理；重复、冲突、撤权、回复与未知发送有回归 | 已完成 |
| 3 | 统一凭据读取及连接授权 | 邮件、业务 HTTP、模型复用异步秘密供应；按工作区/身份授权，轮换不泄露秘密 | 已完成 |
| 4 | 文件产物端口、本地与 S3 实现 | 生成文件、持久引用、下载复核权限/过期/摘要；重放与错误不覆盖旧对象 | 已完成 |
| 5 | 模型配置清单及模块选择 | 同实例不同模型；任务指纹只绑定选中模型，恢复不静默切换 | 已完成 |
| 6 | 扩展模板、配置诊断与三个中立示例 | 生成代码能编译；API 查询、文件生成、消息等待确认可运行 | 已完成 |
| 7 | 工作区/模块并发与公平领取、供应商速率控制 | 多 Worker 不突破配额；租约过期释放容量，低流量工作区不会持续饿死 | 已完成 |

所有扩展都是受信任的静态部署代码，不动态执行用户上传插件。OAuth 授权页面、聊天品牌适配、跨人员审批、SSO 和复杂子任务图不在本轮范围；保留端口供实际业务接入。外部服务使用受控替身验收，不连接真实邮箱、模型或对象存储，不升级用户现有实例。

## 验收证据

- `tests/extensions.test.ts`：第三方注册、秘密轮换、资源关闭、本地/S3 协议与命名模型连接。
- `tests/extensibility.test.ts`：签名渠道到 Worker/等待/回复闭环，跨身份权限、未知投递审计、三个示例、文件重放/清理、配额竞争与模型恢复隔离。
- `tests/scripts.test.ts`：两类扩展骨架编译、重复生成拒绝覆盖。
- `scripts/smoke-compose.mjs`：迁移 009–013、受限运行账号、签名渠道、共享卷文件与重启、邮件兼容、备份与隔离恢复。

接入配置与边界集中在 [通用扩展](extending.md)，保留原邮件和默认模型兼容入口。已实现的限流针对 `Connections` 调用；邮件沿用账户轮询/收发调度。真实供应商互通与大规模容量需部署环境另行验收。

本轮验收：116 项后端测试通过；核心覆盖率行 98.79%、分支 92.92%、函数 97.51%。类型、lint、格式、文档、构建、262 项依赖许可及最终镜像 Compose 验证通过。未修改页面，本轮未重跑浏览器截图测试。
