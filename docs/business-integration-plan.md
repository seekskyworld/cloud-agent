# 业务接入改造计划

目标：新业务增加独立业务包与静态注册配置，不修改核心；替换基础设施通过声明和绑定完成。保留默认免 Token、旧模块/配置/任务兼容，新增能力可选。

| 阶段 | 内容 | 验收 | 状态 |
| --- | --- | --- | --- |
| 1 | 业务包与稳定 SDK | 独立包生成、编译、运行、升级隔离，权限声明和生命周期 | 已完成 |
| 2 | 扩展依赖与诊断 | 缺依赖启动失败，自定义实现诊断无品牌分支，未检查不报成功 | 已完成 |
| 3 | 统一工具/模型失败语义 | 永久错误不重试，限流遵守等待，未知写入不重发 | 已完成 |
| 4 | API 与页面协议 | OpenAPI/类型客户端、输入结果扩展、鉴权附件下载及浏览器验收 | 已完成 |
| 5 | 可选上下文与结构化输出 | 身份/ACL复核、上下文预算、恢复指纹与输出Schema验证 | 已完成 |

本次不增加动态插件沙箱、完整多租户SaaS或自动检查点迁移。外部集成用受控协议服务验证，不改变已有实例和真实数据。

## 验收结果

- `pnpm check`：133 项后端测试通过，含原有 116 项回归；核心行/分支/函数覆盖率为 98.95% / 93.20% / 97.39%。类型、lint、架构边界、文档和构建通过。
- 生成业务包在独立临时项目编译、运行；缺依赖/错误 SDK/权限声明拒绝，业务配置改动隔离旧任务。
- 真实 HTTP 验证类型客户端、OpenAPI 递归引用、附件授权；Pi 401/429、输出预算、结构化结果与失败计费通过受控协议验证。
- 上下文快照重放、跨工作区拒绝、ACL 撤权、取消/超时、文档预算；未知写入不重发及人工核实的幂等/撤权/输出校验通过。
- `pnpm test:browser`：5 项通过，桌面/手机截图已检查；业务包结果展示和实际文件下载通过。隔离浏览器服务有单独测试配额，生产默认 120 次/分钟另有回归。
- 格式、262 项生产依赖许可及差异检查通过；镜像构建与隔离 Compose 验收通过，包含新业务包、追加迁移、运行账号审计/快照不可修改、重启、备份与隔离恢复。

接入入口集中于 [扩展指南](extending.md#独立业务包与-sdk-v1)、[模块与页面](modules.md) 和 [API](api.md)，避免复制平台代码。当前 SDK 为源码应用内公共导出，未独立发布 npm；OpenAPI 覆盖核心任务 API，不包含管理/定时器/供应商回调。真实邮箱、模型及 S3 账号未联调，未进行规模压测；未升级已有运行实例或改动用户数据。
